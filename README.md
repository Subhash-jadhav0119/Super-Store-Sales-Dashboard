# # 📊 Super Store Sales Dashboard | Excel Project

## Project Overview

This project presents an interactive **Super Store Sales Dashboard** built using Microsoft Excel & Power Query . The dashboard provides a clear view of sales performance, transaction volume, order quantity, shipping modes, customer segments, regions, product categories, cities, and monthly ordering trends.

The objective of this project is to transform raw Super Store sales data into meaningful insights that support faster, data-driven business decisions.

## Dashboard Preview

![Super Store Sales Dashboard](images/super-store-sales-dashboard.png)


## Business Problem

Retail businesses generate large volumes of sales and order data. Without a structured dashboard, it can be difficult to identify high-performing regions, cities, customer segments, shipping modes, and product categories.

This dashboard helps stakeholders answer important business questions, such as:

- What is the total sales value and transaction count?
- Which region records the highest number of transactions?
- Which cities generate the highest sales?
- Which product category has the highest transaction volume?
- Which customer segment orders the highest quantity?
- Which shipping mode is most frequently used?
- How does order quantity change from month to month?
